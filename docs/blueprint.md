# **App Name**: Sonko Storefront

## Core Features:

- Dynamic Homepage: Dynamic homepage with featured products and a rotating banner, designed for immediate customer engagement.
- Product Catalog: A clean, navigable product catalog that supports filtering by size, price, and color.
- Product Management: Management tool for adding, modifying, and removing product listings directly from the admin panel.
- Banner Management: Dashboard feature to modify the banners displayed on the homepage, ensuring fresh content and promotions without code deployments.
- AI Ad Copy Tool: AI tool that can generate targeted promotional text for product listings and homepage banners.

## Style Guidelines:

- Primary color: A vibrant green (#66BB6A), reflecting growth and energy, consistent with the brand's colors.
- Background color: Light green (#E8F5E9), a desaturated shade that offers a clean and calming backdrop, ensuring the vibrant green elements stand out.
- Accent color: A deep red (#D32F2F), providing contrast to the green palette for calls to action and important notifications.
- Clean and modern typography optimized for legibility and readability on all devices, enhancing the user experience.
- Custom-designed icons for categories and UI elements, to ensure a visually consistent experience.
- Responsive, grid-based layout, that will adapt fluidly to different screen sizes.
